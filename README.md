# QuizMaster - Interactive Quiz Application

A comprehensive, production-ready quiz application built with React 19, Vite, and Tailwind CSS. This application tests knowledge on Vercel deployment, Git version control, and GitHub integration through 100 carefully crafted questions.

## 🚀 Features

- **100 Questions** covering Vercel, Git, and GitHub topics
- **Multiple Question Types**: Multiple Choice, True/False, Fill in the Gap
- **Instant Feedback** with visual indicators (✅ Good / ❌ Fail)
- **Progress Tracking** with animated progress bar
- **Timer** to track completion time
- **Dark/Light Mode** toggle
- **Responsive Design** - Works on desktop, tablet, and mobile
- **Keyboard Navigation** support
- **Review Answers** functionality
- **Detailed Results** with pass/fail breakdown
- **Animated Transitions** using Framer Motion
- **Local Storage** for quiz state persistence
- **Professional UI** with glassmorphism effects

## 📋 Prerequisites

- Node.js (v18 or higher)
- npm or yarn package manager
- Git (for version control)
